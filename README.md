# Support Ticket Tracker

A Java-based support ticket management application built as part of my backend software engineering learning roadmap.

## Overview

The Support Ticket Tracker demonstrates core Java programming and object-oriented programming concepts through a practical help-desk style application.

The application allows support tickets to be created, managed, searched, filtered, assigned to users, and summarized.

## Features

- User management
- Support ticket management
- Ticket status management
- Ticket priority management
- Ticket assignment
- Ticket reassignment
- Search tickets by title
- Search tickets by description
- Search by status
- Search by priority
- Search by assigned user
- Keyword searching
- Compound ticket searches
- Ticket counting and reporting
- Highest and lowest priority ticket detection
- Active ticket tracking
- Unassigned ticket handling
- Ticket summary reporting

## Java Concepts Demonstrated

- Classes and objects
- Constructors
- Methods
- Encapsulation
- Getters and setters
- Enums
- `ArrayList`
- Loops
- Conditional logic
- Exception handling
- Input validation
- File I/O concepts
- Searching and filtering collections
- Object-oriented design
- Java compilation and execution
- Basic project testing and verification
